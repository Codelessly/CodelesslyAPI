What changes in a document
The full mapping is in v2/DESIGN.md, section 6.
v1v2
frame, rectangle with children→stack
rectangle→box
rowColumn→row or column
Stored boxes, pins, positioning mode→layout: one fit and one position per axis
v1 defaults→Flutter's defaults; v1 values written where they differ
variables binding keys→bind paths (fill → decoration.fills[0])
One reaction per action→Reactions with chains
Variable values as text→Typed values; ${= ...} becomes a formula
From the command line
migrate_pages prints coverage: how many nodes, and what was not mapped.
$ cd v2/migrate $ dart pub get # A directory of stored v1 page documents to v2 layout documents. $ dart run bin/migrate_pages.dart <in-dir> <out-dir> # A v2 publish bundle (gzipped JSON) from v1 page documents. $ dart run bin/publish_fixture.dart <out.json.gz> <page.json.gz>...
publish_fixture treats canvases named <Screen> · M, · T and · D on one page as one layout with three breakpoints.
