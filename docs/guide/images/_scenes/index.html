The data model of Codelessly
What the Editor saves, what a publish contains and what the SDK renders. Pure Dart.
Editor
saves layouts
codelessly_api
Flutter's widgets as data
Nodes, layouts, logic, publishes, with a JSON format. No Flutter, no network.
codelessly_sdk
renders it in Flutter
Your tools
Servers, CLIs, code generators, tests: read, build, check or transform layouts.
Showing layouts in an app? Use the SDK: it exports this package.
