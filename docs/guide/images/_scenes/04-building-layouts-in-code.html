Things to get right
Every node has a unique id, and its map key is that id A node appears once, as a child or a slot of one parent Roots are canvases; a canvas's content is its body slot Nodes have a size: Layout() defaults to a fixed 0 × 0 Raw strings (r'...') for text with expressions, so $ isn't interpolated
